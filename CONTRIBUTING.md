# Suggestions and corrections

Two ways to contribute, both through issues.

**Submit a number** — you have a throughput / training-time / latency measurement with hardware, version and a
command. Use the *submit a number* template.

**Correct a row** — a link moved, a claim was misquoted, a number does not match the source. Say which row and
what the source actually says.

## What happens next

- Rows enter as `UPSTREAM` or `3P`; nothing enters as `MEASURED` unless the artifact is in a public repo.
- If you disagree with an existing row, it gets both numbers and a note. Rows are not deleted to settle arguments.
- Formatting is not a reason to reject a row; missing hardware or version is.

## Style for table edits

Keep cells short. Put the nuance in prose under the table, not into the cell — a table cell that needs three
clauses to be true is a paragraph wearing a table costume.
